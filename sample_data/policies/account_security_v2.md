# VaaniDesk Account Security Policy (v2)

**Effective date:** 10 May 2026

## Passkey Login (New)

VaaniDesk supports **WebAuthn passkeys** on supported browsers and Android 14+ / iOS 17+. Passkeys can replace password for daily login; password remains backup recovery method.

## Device Trust Scoring

New devices receive **trust score** based on behavioral signals. Low-trust first orders may require card 3DS step-up even if saved card exists.

## API Token Policy (Developer Accounts)

Seller and affiliate API keys rotate every **90 days**. Keys displayed once at creation—store in secrets manager, never commit to Git.

## Incident Response SLA

Security team acknowledges **security@vaanidesk.in** reports within **4 business hours** for active exploitation reports; 24 hours for general phishing tips.
