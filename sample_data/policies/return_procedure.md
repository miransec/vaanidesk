# VaaniDesk Return Procedure

**Effective date:** 1 January 2026

## Eligibility Overview

Most VaaniDesk SKUs qualify for **10-day return** from delivery unless marked **Non-Returnable** on the product page. Exceptions include hygiene products, opened software, innerwear, and perishables.

## Return Reasons We Accept

- Changed mind (unused, original condition)
- Wrong item shipped (VaaniDesk error—free return + apology credit)
- Size / fit exchange preference (may route to exchange policy)
- Missing accessories documented at unboxing

## Return Reasons We May Decline

- Product shows use, stains, or missing tags
- Return window expired
- Non-returnable category
- Serial number tampered or IMEI blacklisted after activation

## Step-by-Step Return Process

### Step 1: Initiate Return

**My Orders → Return Item → Select reason → Upload photos**

System generates **Return Merchandise Authorization (RMA)** number. Returns without RMA may be rejected at hub.

### Step 2: Pack Securely

- Original box preferred; otherwise sturdy carton
- Include all accessories, manuals, freebies
- Affix RMA label printed from app or write RMA on outer box
- Remove old shipping labels

### Step 3: Pickup or Drop-off

- **Doorstep pickup:** Free for eligible PIN codes; schedule 3-hour window
- **Drop-off:** VaaniDesk partner stores or Blue Dart drop boxes (list in app)

Pickup attempts: 2; missed pickups may convert to self-ship with reimbursement up to ₹100 on receipt.

### Step 4: Quality Check (QC)

Hub QC completes within **48 hours** of receipt. Status updates: Received → Inspecting → Approved/Rejected.

### Step 5: Refund or Exchange

Approved returns trigger refund per refund_timeline.md or exchange per exchange_policy.md.

## Partial Returns

Multi-quantity line items: return subset if each unit individually packed with same RMA (quantity noted).

## Marketplace Returns

Seller fulfillment: return ships to seller hub; VaaniDesk mediates QC disputes if seller rejects unfairly.
